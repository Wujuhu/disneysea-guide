# 一、海洋漫游：东京迪士尼海洋导览

无需安装前端依赖、无需构建的中文 HTML 项目。官方地图为主，一句话项目介绍与一日游时间表为辅。

## 1. 打开

在线访问：<https://wujuhu.github.io/disneysea-guide/>。

直接用浏览器打开 index.html。图片、地图、字体与脚本均已保存在本地。

也可在本目录运行：

    python tools/serve.py

打开 <http://127.0.0.1:4173>。用 --port 4174 更换端口，Ctrl+C 停止。预览仅监听本机。

## 2. 当前功能

- 放大的官方地图，分区只留轻淡底色，取消粗分隔线。
- 全页采用侧边导航：地图、时间表、DPA、吃饭。地图铺满剩余视口高度，项目列表和攻略内容独立滚动。
- 默认按官方地图指北针逆时针约 105° 校正为上北下南、左西右东，可一键切回官方原图方向；点位、分区、路线同步转换，网页名称与序号保持正向。
- 导航栏可收起为图标窄栏，桌面项目列表可独立收起；设置与地图朝向刷新后保留。
- 英文原名仅在打开项目详情后显示，可完整阅读；地图、项目列表和时间表保持中文，英文名称仍支持搜索。
- DPA 适用项目使用带深色边缘的高对比度绿圈，标记尺寸不变；服务适用不代表实时库存。
- 路线项目名称常显，使用小字号；餐厅、小吃和其他项目名称仅在悬停或键盘聚焦时出现。
- 标记与文字分层，密集标记轻微错位并用细线指回原位置；缩放、拖动和键盘定位共用同一相机状态。
- 标记在独立的屏幕坐标层绘制，路线项目约 24px，餐厅 20px；筛选只淡化不匹配项，不再整批隐藏点位。分区点击不再产生矩形焦点框，键盘可用园区筛选框操作。
- 33 个项目／体验／交通记录（龟龟漫谈、小飞侠 2 项默认排除）、2 场水上演出，以及 23 个餐厅／小吃记录；可见数量随所选日期的官方停运和统一隐藏开关变化。
- 美人鱼礁湖的 5 个室内项目在大地图上合并为“美人鱼礁湖 · 室内区”一个点，点开后选择小项目查看详情；各项目仍可单独搜索。
- 每个项目使用通俗的一句话玩法，突出倒退、失重、360° 倒转等特色；详情与列表显示体验时长，不含排队。
- 已公布日期的演出详情列出具体场次；二月未公布日期明确显示待公布。
- 中英文与别名搜索，分区、五大项目、DPA、室内等筛选。
- 拖动、滚轮／双指缩放、复位、键盘平移；手机可切换地图和清单。
- 路线内直接显示 1、2、3 等游玩顺序，其余项目为实心小圆点，不再显示原始编号及额外角标。
- 清单按“全部／项目／演出／餐厅／其他／隐藏”筛选；其他收录交通体验。餐厅再按订座、须手机点餐、无需订座筛选，地图同步淡化不匹配项。
- 紫色连线只连接项目与演出，餐厅不接入路线；午晚餐只留就近简餐预算。“显示连线”只隐藏线，游玩序号保留。
- 五个重点项目有固定小星标；普通点采用深色白边，提高地图上的对比度。
- 五大项目基准：Soaring、地心探险、印第安纳琼斯、忿怒双神、惊魂古塔。按日期替换检修项目。
- 时间表包含大约时点、体验时长、排队与步行预算、用餐和演出预留，可导出文字。
- DPA 教程解释入园后购买、各项目／时段分别看余票、个人再次购买资格和两个具体时间例子；不编造统一定时补票表。价格表按排除与停运设置过滤。
- 餐饮列出 6 家建议订座、3 家须手机点餐，以及无需订座的快餐和小吃；樱花等按所选日期隐藏已确认停运。订座说明提前一个月 10:00、当天网上 09:00、门口有空位 10:00；日本／北京时间并列。
- 用餐页签、折叠区和开关沿用本地 Bootstrap 5.3.8，页面主入口改为侧边导航。
- 两位成人逆时针主环线：翱翔、海港花船、神秘岛、忿怒双神、梦幻泉乡冰雪奇缘、印第安纳琼斯、美国海滨古塔，最后回海港；梦幻泉乡进出经过同一片连接区。
- DPA 旁注与主行程间隔 24px，整段时间线最大宽 940px，不随宽屏拉远。入园先查冰雪奇缘，后续按 60 分钟／使用开始时间的较早值计算购买资格。普通日按冰雪奇缘与古塔 DPA 预算，两位成人约 ¥8,000；提前闭园日加忿怒双神，约 ¥11,000。其余旁注为可选购买。
- 名称对照官方简体中文目录，保留常用称呼用于搜索；火鸡腿与辣味熏鸡腿分别标出。
- 已移除“第一次来”和“怎么看地图”。统一“显示隐藏项目”开关恢复或隐藏官方停运和用户主动隐藏的全部记录；收藏与“我的想玩”仍未启用。
- 默认关闭“显示隐藏项目”：按当前日期隐藏官方停运／停演及用户主动隐藏项，普通清单、地图和攻略同步；“隐藏”分类始终可查全部隐藏记录及原因，并按两类原因筛选。未公布演出场次继续保留；室内子项目同样处理。

## 3. 用户出行窗口

窗口为 **2027 年 2 月 1–6 日**。默认展示 **2 月 6 日预算草案**，不代表用户已选定该日，可在攻略右上方的日期控件切换。

核对时，2 月 1–4 日及 6 日营业为 09:00–21:00；5 日为 09:00–18:30，均为日本时间。地心探险于 1 月 8 日至 3 月 8 日检修，路线用同一区的海底两万里替代。Believe! 在 2 月 1–5 日列入停演；6 日未列入，但具体场次未公布。

二月演出只显示“午前预留／晚间预留、场次待公布”，不会把内部预算写成官方开演时间。前后行程时点也须随正式场次调整。官方月度场次通常在前一个月 8 日左右公布，需要在 2027 年 1 月上旬复核。

例如夜秀在 2 月 1–5 日有官方停演记录，这些日期会隐藏；2 月 6 日未列停演，虽具体场次未公布，仍会保留并标注待公布。

## 4. 文件分工

- index.html：界面、DPA 与用餐教程。
- styles.css：桌面／手机布局、分区、标记与路线。
- app.js：地图、搜索、筛选、详情、日期与导出。
- data.js：项目、点位、价格、分区、营业日历、演出与检修。
- planner.js：独立的时间预算与替代逻辑。
- assets/：本地官方地图、照片与字体；字体许可见 FONT-LICENSE.txt。
- research/sources.json、research/experience-facts.json、SOURCES.md：素材、体验时长与事实来源。
- tools/serve.py：可选本地预览；tools/check-planner.cjs：时间预算检查。
- PRODUCT.md、DESIGN.md：产品范围与设计约定。

## 5. 数据边界与维护

基础资料核对日为 **2026-11-01**；餐饮服务、DPA 规则补核于 **2026-11-03**。页面没有实时排队、库存、点餐或订位接口，不进行购买。价格和 DPA 规则是当前参考，2027 年出发前需复核。

点位和分区边界为人工导览标注；紫线是游玩顺序，**不是步行导航**。官方底图原有编号和小字保留。只展示全园主图，美人鱼礁湖的 5 个室内项目共用建筑入口附近的一个点位，具体项目在详情内展示；点位不表示室内的精确布局。

固定乘骑／剧场时长来自官方；要塞、日文解谜和爱丽儿游乐场的建议停留时间由本导览估计，并单独标记。排队、步行、用餐与机动时间均为预算，实际预约、天气和运营优先于模板。

data.js 的点位仍使用原始官方图坐标；app.js 在渲染时按指北针旋转，并以园区轮廓计算适配范围。维护点位时不应把新方向下的屏幕坐标直接写回原始数据。

维护时先查官方来源，再更新 data.js 与 planner.js。补齐演出场次后，预留行会自动显示对应已公布时间。tools/download-font.py 可刷新字体子集，需 requests、fonttools、Brotli；正常打开网页不需要这些包。

计划检查覆盖 2026 年 11 月、2027 年 2 月共 58 天：无时间重叠、不越过闭园、不含已公布检修项目，未知演出不生成确定场次。浏览器检查覆盖搜索、筛选、详情、区域展开、路线开关、日期切换、用餐页签与文字导出。

## 7. 发布到 GitHub Pages

仓库：<https://github.com/Wujuhu/disneysea-guide>。

向 main 分支推送后，.github/workflows/pages.yml 会自动检查 JavaScript 和 58 天的行程预算，然后发布网页。也可在 GitHub 的 Actions 页面选择 Deploy GitHub Pages，手动运行发布。

本轮核心 CSS／JavaScript 使用统一资源版本参数，避免更新界面后混用旧缓存。后续同时修改页面结构和脚本时，应同步更新 index.html 中的该版本。

Pages 的发布来源设为 GitHub Actions。发布目录只包含 index.html、styles.css、app.js、data.js、planner.js 与 assets/。源码说明和来源记录保留在仓库中；研究用原始 PDF、重复地图图片和本地审查截图不上传。
